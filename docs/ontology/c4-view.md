# View terms (c4v:)

How the architecture explorer draws a model: order, grid positions, colours, the opening view, pins, legend and level names. Together with the [core terms](c4.md) they let a page be recreated from its RDF graph. Every property here is an OWL annotation property: nothing in this module changes what the architecture means. This page is the target of the namespace `https://caviri.github.io/c4-model-agentic-plugin/ontology/c4-view#`, generated from [`c4-view.ttl`](c4-view.ttl) when the site is built.
