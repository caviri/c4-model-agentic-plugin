# History terms (c4h:)

Versions of an architecture over time, with provenance: which architecture each commit, merge, release or pull
request held, who changed what and when, and what changed between two versions down to single triples. Built on
[PROV-O](https://www.w3.org/TR/prov-o/); the architecture inside each version is in the [core terms](c4.md) and the
[view terms](c4-view.md). This page is the target of the namespace
`https://caviri.github.io/c4-model-agentic-plugin/ontology/c4-history#`, generated from
[`c4-history.ttl`](c4-history.ttl) when the site is built. Datasets are checked with
[`c4-history-shapes.ttl`](c4-history-shapes.ttl). [History and diffs](../history.md) shows the module at work.
